# Chat Application

A client-server chat application built using Node.js and JavaScript.

## Overview

This project demonstrates the fundamentals of socket-based communication between a client and a server. It was developed to understand networking concepts, message exchange, and backend application development using JavaScript.

## Features

- Client-server communication
- Message exchange between users
- Server-side request handling
- Modular project structure
- Package management using npm

## Technologies

- JavaScript
- Node.js
- npm

## Project Structure

```
chat-application/
│
├── client1.js
├── server1.js
├── package.json
├── package-lock.json
├── babel.config.json
└── .github/
```

## Learning Objectives

- Understand client-server architecture
- Learn Node.js backend development
- Practice JavaScript networking concepts
- Work with npm packages
- Organize a backend application
